# cochive-org 공통 GitHub 템플릿

이 저장소는 `cochive-org`가 소유한 저장소에 공통으로 적용되는 Community
Health 파일을 관리합니다.

- Pull Request 작성 시 공통 체크리스트를 제공합니다.
- 버그 제보와 기능 요청을 구조화된 Issue Form으로 받습니다.
- 개별 저장소에 같은 종류의 템플릿이 있으면 개별 저장소 설정이 우선합니다.

템플릿에는 비밀정보나 저장소별 내부 정보를 포함하지 않습니다.
